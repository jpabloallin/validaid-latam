# ValidaID LATAM: valida NIT, RUT, CUIT, CNPJ y RFC en tu navegador

[ValidaID LATAM](https://validaid-latam.pages.dev/) revisa el dígito verificador y la estructura de identificadores tributarios de Latinoamérica, uno por uno o en lote desde archivos CSV/XLSX. Todo corre en el navegador: los archivos nunca se suben ni se guardan en ningún servidor.

## Herramientas por país

| País | Identificador | Herramienta |
|---|---|---|
| Colombia | NIT (DV, fórmula DIAN) | [Calcular DV del NIT](https://validaid-latam.pages.dev/calcular-dv-nit/) |
| Chile | RUT (incluye la K) | [Validar RUT chileno](https://validaid-latam.pages.dev/validar-rut/) |
| Argentina | CUIT / CUIL | [Validar CUIT](https://validaid-latam.pages.dev/validar-cuit/) |
| Brasil | CNPJ / CPF | [Validar CNPJ](https://validaid-latam.pages.dev/validar-cnpj/) |
| México | RFC | [Validar RFC](https://validaid-latam.pages.dev/validar-rfc/) |

## Para qué sirve

- Limpiar bases de clientes o proveedores antes de cargarlas a un ERP, CRM o core bancario.
- Detectar errores de digitación en NIT, RUT, CUIT, CNPJ o RFC sin escribir un script.
- Revisar archivos CSV/XLSX completos en segundos: gratis hasta 25 filas; [licencia de por vida por USD 19](https://9777141745128.gumroad.com/l/qepzjm) para lotes completos.

## Qué no hace

Solo valida el dígito verificador y la estructura del identificador. No consulta registros oficiales (DIAN, SII, AFIP, Receita Federal, SAT) ni hace verificación de identidad (KYC).

## Privacidad

El procesamiento es 100 % local en el navegador. No hay subida de archivos ni almacenamiento de datos.
